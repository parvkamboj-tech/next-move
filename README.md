# NEXT MOVE

## Intelligent Warehouse Order Picking & Dynamic Route Optimization System

NEXT MOVE is a Data Structures and Algorithms based smart warehouse system designed to optimize product picking and warehouse navigation.

### Core Features
- Product and inventory management
- Product availability validation
- Alternative product suggestions
- Warehouse location mapping
- Order and priority management
- Graph-based warehouse navigation
- BFS, DFS and Dijkstra
- Dynamic route re-routing
- Worker-oriented interface
- Picking performance analysis

### Technologies
- C
- C++
- Data Structures & Algorithms
